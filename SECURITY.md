# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately to `info@solkn.com` with the affected URL or component, reproduction steps, and potential impact.

We will acknowledge reports as soon as practical, investigate them, and coordinate remediation and disclosure with the reporter. Never include live credentials, personal data, or customer data in a report.

## Supported version

Security fixes are applied to the current production version on the default branch.
